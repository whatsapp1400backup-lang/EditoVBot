# جعبه‌ابزار محتوا 🎬

ربات تلگرام **@Edito_VBot** — جعبه‌ابزار کامل ویدیو و محتوا: ویدیو را از کاربر می‌گیرد و خروجی تمیز و آماده‌ی
آپارات تحویل می‌دهد — بدون اینکه آپارات به حجم، ابعاد یا فرمت گیر بدهد.
ربات روی **همین سرور** اجرا می‌شود؛ Railway لازم نیست.

## خروجی ربات (مطابق قوانین رسمی آپارات)

| حالت | ابعاد | نسبت | فرمت |
|---|---|---|---|
| 🎬 معمولی | 1920×1080 | 16:9 | MP4 ‏(H.264 + AAC)‏ |
| 📱 شورتس | 720×1280 | 9:16 | MP4 ‏(H.264 + AAC)‏ |
| 🗜️ فشرده | 1280×720 | 16:9 | MP4 ‏(H.264 + AAC)‏ |
| 🗜️ کم کردن حجم | همان رزولوشن (حداکثر 1080p) | همان | MP4 ‏(H.264 + AAC)‏ |

- حجم خروجی همیشه زیر **۱/۵ گیگابایت** نگه داشته می‌شود (سقف حساب معمولی آپارات).
- اگر خروجی اول بزرگ‌تر شد، ربات خودش دوباره با فشرده‌سازی بیشتر تبدیل می‌کند.

## امکانات دیگر

- **🎵 استخراج صدا** — بعد از فرستادن ویدیو، صدایش را جدا می‌کند و MP3 می‌دهد.
- **🔗 دانلود از لینک** — لینک یوتیوب، ریلز اینستاگرام یا آپارات را بفرستید؛ ویدیو را دانلود می‌کند و می‌فرستد (حداکثر ۵۰ مگابایت، سقف ارسال تلگرام).
- **🎬 ریلز گردی** — ویدیوهای کوتاه یوتیوب شورتس و آپارات شورتس را یکی‌یکی نشان می‌دهد؛ با دکمه‌ی «بعدی» ورق می‌زنید.

## ⚠️ محدودیت مهم — سقف ۲۰ مگابایت ورودی

تلگرام به ربات‌ها فقط اجازه می‌دهد فایل تا حدود **۲۰ مگابایت** را با
`getFile` دانلود کنند. ویدیوی بزرگ‌تر از ۲۰ مگابایت دانلود نمی‌شود و
ربات همین را به‌صراحت به کاربر می‌گوید. برای ویدیوی بزرگ‌تر باید اول
فشرده‌اش کرد یا تکه‌تکه فرستاد.

## چرا Bot API (نه Telethon)؟

اتصال مستقیم MTProto (Telethon) از این سرور بسته است — هنگام ساخت کلید
احراز هویت قطع می‌شود. ولی فراخوانی HTTPS به `api.telegram.org` بدون
مشکل کار می‌کند، پس ربات با **python-telegram-bot نسخه ۲۱+** و polling
روی Bot API اجرا می‌شود.

## طرز کار

1. کاربر در تلگرام به **@Edito_VBot** می‌رود و `/start` می‌زند.
2. از منوی اینلاین حالت را انتخاب می‌کند (معمولی / شورتس / راهنما).
3. ویدیو را می‌فرستد — ربات مشخصاتش را نشان می‌دهد (ابعاد، مدت، حجم).
4. حالت خروجی را از دکمه‌ها انتخاب می‌کند.
5. ربات با ffmpeg تبدیل می‌کند و فایل MP4 آماده‌ی آپارات را می‌فرستد.

## اجرا روی همین سرور

نصب یک‌باره:

```bash
cd ~/workspace/edito-vbot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
# ffmpeg باید نصب باشد (روی این سرور نصب است)
```

اجرا (در پس‌زمینه):

```bash
BOT_TOKEN="..." nohup ./run.sh > bot.log 2>&1 &
```

> ⚠️ توکن را هیچ‌وقت داخل کد یا گیت‌هاب نگذار؛ فقط به‌عنوان متغیر محیطی.

نکته‌ی فنی: اسکریپت `run.sh` متغیر `no_proxy` را به یک لیست ساده محدود
می‌کند، چون لیست سیستمی شامل آدرس‌های IPv6 داخل `[]` است که httpx
نمی‌تواند تجزیه کند و ساخت ربات با خطای `InvalidURL` می‌شکند.

## فایل‌ها

- `bot.py` — کد اصلی ربات (python-telegram-bot + ffmpeg + yt-dlp)
- `requirements.txt` — وابستگی‌ها (python-telegram-bot ،yt-dlp)
- `run.sh` — اجرای ربات روی همین سرور
- `Dockerfile` — ایمیج با ffmpeg (اختیاری)
