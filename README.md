# Edito_VBot — ربات تبدیل ویدیو برای آپارات 🎬

ربات تلگرام **@Edito_VBot**: ویدیو را از کاربر می‌گیرد و خروجی تمیز و آماده‌ی
آپارات تحویل می‌دهد — بدون اینکه آپارات به حجم، ابعاد یا فرمت گیر بدهد.

## خروجی ربات (مطابق قوانین رسمی آپارات)

| حالت | ابعاد | نسبت | فرمت |
|---|---|---|---|
| 🎬 معمولی | 1920×1080 | 16:9 | MP4 ‏(H.264 + AAC)‏ |
| 📱 شورتس | 720×1280 | 9:16 | MP4 ‏(H.264 + AAC)‏ |
| 🗜️ فشرده | 1280×720 | 16:9 | MP4 ‏(H.264 + AAC)‏ |

- حجم خروجی همیشه زیر **۱/۵ گیگابایت** نگه داشته می‌شود (سقف حساب معمولی آپارات).
- اگر خروجی اول بزرگ‌تر شد، ربات خودش دوباره با فشرده‌سازی بیشتر تبدیل می‌کند.
- ویدیوی ورودی تا **۲ گیگابایت** (سقف تلگرام) قبول می‌شود — چون ربات با
  Telethon و MTProto کار می‌کند، نه Bot API معمولی که فقط تا ۲۰ مگابایت دانلود می‌دهد.

## طرز کار

1. کاربر در تلگرام به **@Edito_VBot** می‌رود و `/start` می‌زند.
2. از منوی اینلاین حالت را انتخاب می‌کند (معمولی / شورتس / راهنما).
3. ویدیو را می‌فرستد — ربات مشخصاتش را نشان می‌دهد (ابعاد، مدت، حجم).
4. حالت خروجی را از دکمه‌ها انتخاب می‌کند.
5. ربات با ffmpeg تبدیل می‌کند و فایل MP4 آماده‌ی آپارات را می‌فرستد.

## اجرا روی Railway (پیشنهاد اصلی)

1. در [railway.app](https://railway.app) وارد شو و **New Project → Deploy from GitHub repo**
   را بزن (یا همین پوشه را به یک ریپوی گیت‌هاب بفرست و وصل کن).
2. در بخش **Variables** این سه متغیر را اضافه کن:
   - `BOT_TOKEN` — توکن ربات از BotFather (برای @Edito_VBot)
   - `API_ID` — از [my.telegram.org](https://my.telegram.org) (ساخت اپلیکیشن)
   - `API_HASH` — از [my.telegram.org](https://my.telegram.org)
3. Railway خودش با Dockerfile بیلد می‌کند (ffmpeg داخل ایمیج نصب می‌شود).
4. در لاگ باید ببینی: `Edito_VBot در حال اجرا...`

> ⚠️ توکن را هیچ‌وقت داخل کد یا گیت‌هاب نگذار؛ فقط در Variables ریلی‌وی.

## اجرای محلی

```bash
pip install -r requirements.txt
# ffmpeg باید نصب باشد: sudo apt install ffmpeg
export BOT_TOKEN="..."
export API_ID="..."
export API_HASH="..."
python bot.py
```

## فایل‌ها

- `bot.py` — کد اصلی ربات (Telethon + ffmpeg)
- `requirements.txt` — وابستگی‌ها (telethon)
- `Dockerfile` — ایمیج با ffmpeg
- `railway.json` — تنظیمات دیپلوی ریلی‌وی
- `Procfile` — (اختیاری)
